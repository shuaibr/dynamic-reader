# ADR 0003 — Adopt portfolio operations; mena/maruf naming

**Context:** Spec pack v2 names six portfolio projects governed by a shared
OPERATIONS.md (WIP cap, forced-choice outputs, AOR, R2R, meta-work quarantine).
Two of the six live in this repo. PRINCIPLES.md v2 is unchanged from what
ADR-0001 already folded into AGENT_PRINCIPLES.md.
**Decision:** Commit copies of OPERATIONS.md, the mena product spec, mena's
framework-alignment, and the maruf spec (renamed from sufi-text-companion);
workspace root remains their source of truth. Workstreams renamed: mena
(1–2), maruf (5). The other four projects (flow, reeyaz, sama, scout) are
out of scope for this repo. Under Rule 3 the repo is Passive (Active: flow);
the pending validation runs complete an already-committed milestone.
