# Humaniti Report Format

- Audience: program leads and grant writers. Precise, sober, no hype.
- Structure: Executive Summary (<=200 words) -> Key Findings (numbered,
  each with citations) -> Analysis -> Limitations -> Sources.
- Every number gets a citation and a year. "Recent" is banned; use dates.
- Limitations section is mandatory: name what couldn't be verified, which
  language track was thin, and known data gaps.
- Close the Sources list with the language-coverage line so the MENA data
  gap is visible in every deliverable.
